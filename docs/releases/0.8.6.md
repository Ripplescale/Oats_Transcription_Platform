# oats 0.8.6

Browse Home and other saved notes while a meeting keeps recording and
transcribing. Return to recording opens the same session, with its live notes,
transcript, pause/resume and Finish controls. Pending edits remain protected.
Finishing a recording in the background keeps the note you are viewing open.

This release retains the installed 0.8.5 checkpoint-recovery and worker-scheduling
fixes: an unreadable finished checkpoint remains inspectable without blocking
later recordings, and transcription can run alongside one speaker-labeling job.
Saved audio and previously imported transcript text are preserved.

Signed releases now use the renamed GitHub repository. The release workflow is
bound to its stable repository ID and runs regression checks before packaging.
The update feed retains the redirected download address accepted by existing
updater-enabled installations. New builds accept both names for the same signed
Windows installer. Downloads and installation remain separate user actions.

Browser checks use fictional notes and recording events. They verify navigation,
pending-save protection, background transcript updates, pause/resume and one
capture/job identity. They do not establish physical capture quality or device
latency. No local app installation is part of publishing this release.
