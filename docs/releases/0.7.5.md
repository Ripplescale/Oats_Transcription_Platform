# oats 0.7.5

Settings and About replace the sidebar. Home contains note and folder actions, including tags, filtering, moving and confirmed deletion. Removing a folder keeps its notes under Unfiled.

User mode is the default; Dev mode restores transcript diagnostics and source labels. Switching modes preserves editor state, recording, correction drafts, playback and reading position. Transcript bubbles fit their content.

Live and saved notes support inline formatting, headings, lists, checklists, links, quotes and horizontal rules, with undo/redo and autosave. Existing plain text remains readable without migration. Recovery drafts and concurrent-edit checks protect unsaved work.

Validation covered the production frontend, Windows native compilation, formatting/autosave and workspace tests, and synthetic browser workflows. Installation checks verified data preservation separately. These checks did not qualify physical dictation or live meeting-call behavior.

Dictation was introduced in a later release. See [User mode and notes](../USER_MODE_NOTES.md).
