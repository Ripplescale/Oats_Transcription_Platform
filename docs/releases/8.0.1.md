# Historical version label: oats 8.0.1

An early local dictation build used the mistaken **8.0.1** version label. The intended series was restored with a separately built [0.8.1](0.8.1.md) package. This note records that historical distinction; it does not identify the current installed version.

The build introduced bounded default-microphone dictation, **Ctrl+Alt+Shift+D**, optional Copilot-key registration, a nonactivating recording indicator and foreground-target checks. Results were delivered after Stop or retained for explicit Copy. Notes, formatting, tags and meeting detection remained available.

It also introduced [storage retention](../STORAGE_RETENTION.md): verified archives retain exact original recording bytes; reproducible completed-job audio caches can be removed; generated metadata retains a bounded history. User notes, corrections and folder history remain intact. Archive-compatible restoration is required before older workers process compacted sessions.

Validation covered capture normalization, worker cancellation/cleanup, Unicode input packet construction, shortcut handling, target checks, archive corruption and exact restoration, worker exclusion, generated-history retention, frontend/native builds and data preservation. Synthetic and read-only installed checks did not qualify physical microphone use or cross-app typing.

The corrected 0.8.1 package preserves the application and data identities. Version comparison treats 8.0.1 as newer than 0.8.1, so any transition from that historical build must use an explicitly reviewed downgrade-capable installer rather than relabelling existing bytes.
