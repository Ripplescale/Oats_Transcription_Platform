# oats 0.8.1

This version corrects the earlier local **8.0.1** label to the intended 0.8.x series. The application identifier, executable name, installer identity and saved-data directory are unchanged. Historical binaries are not relabelled; the corrected version requires its own package.

## Dictation preparation and overlapping work

A persistent dictation worker prepares the local Trelis model while meeting work is idle and reuses it between requests. Idle eviction, cancellation and worker failures release the model. Preparing ahead of a shortcut reduces repeated startup work but does not eliminate cold loading.

During longer capture, completed fixed windows are processed in the background. Final processing reuses a window only when the session, settings and exact normalized PCM match. Stop includes all remaining audio. This version delivers text after Stop; live confirmed phrases were introduced in 0.8.2.

## Meeting worker efficiency

- Unity analysis gain reuses the speech detector's raw pass instead of repeating identical work. Boosted analysis remains unchanged.
- Status checkpoints use compact JSON without changing nested content, Unicode, atomic replacement or retry behavior.
- Consecutive unchanged idle checkpoints are suppressed. Canonical transcript, recovery-attempt and terminal writes remain unconditional.

The model, prompts, window sizes, token limits and repetition-recovery behavior remain unchanged. Existing historical jobs retain their immutable runtime snapshots. Updating worker source for future jobs is separate from changing those snapshots.

Validation covered worker lifecycle, PCM cache identity, cancellation, context recovery, immediate canonical-result durability, nested Unicode round-trips, unchanged default manifest formatting and failed atomic writes. Compatibility and runtime-tool tests passed. Private saved-job timings and recordings are not part of the published release evidence, and no end-to-end meeting speedup is claimed.
