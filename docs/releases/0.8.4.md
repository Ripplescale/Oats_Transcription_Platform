# oats 0.8.4

Dictation keeps a verified transcript when Windows temporarily locks a request
file during cleanup. Deletion is retried briefly and remaining cleanup stays
bounded to the worker's own request directories. A cleanup-only failure no
longer discards successful recognition or turns it into a Copy-only error.
Cancellation and transcription failures still stop the owned worker and preserve
their original outcome. Pending cleanup has a storage limit.

The dictation popup uses one cream surface with native rounded corners. Starting
and finishing show a compact processing indicator and Cancel; Stop and actual
microphone bars appear during listening. Results and errors retain readable,
scrollable text and explicit Copy/Close controls. The popup remains draggable,
remembers placement and preserves the destination's keyboard focus.

Trelis phrase streaming, target checks, shortcuts, saved-title editing and
notify-first update controls are retained. Installing 0.8.4 applies this update;
source publication does not activate GitHub release delivery.

Validation passed: production frontend export, 41 focused frontend tests,
12 popup behavior groups, 23 dictation-engine tests and 16 Windows input/surface
tests. Cleanup tests use actual synthetic WAV files with Windows sharing locks,
exercise cancellation and worker reuse, and enforce bounded storage and owned
paths. Native surface tests check rounded corners and resize/DPI geometry on an
owned hidden window. The full Windows application compile check passed. Signed
installation and installed-app checks passed: protected data was unchanged,
Trelis loaded, title editing cancelled without saving, and the hidden dictation
WebView and native rounded boundary matched the expected slim popup.

Browser previews and hidden-window tests do not establish live microphone,
target-app typing or native WebView appearance on every device. Those remain
installation/physical acceptance checks. The precise process that held the
reported temporary-file lock was not identified; the verified result is now
independent of that cleanup outcome.
