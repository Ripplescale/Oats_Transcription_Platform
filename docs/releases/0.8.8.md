# oats 0.8.8

Quiet microphone windows are omitted from the visible transcript and exports.
For new transcription jobs, a window is omitted before speech detection and
decoding when no 20 ms frame exceeds RMS 0.006 (about -44.4 dBFS). This intentional
volume policy excludes faint background voices and computer-audio leakage,
including real speech below the cutoff. Computer audio and unknown sources are
exempt, and original recordings are retained.

Exact Devanagari hesitation fillers now appear as Roman `uh`, `umm` and `hmm` in
live and saved transcripts and exports. Other Hindi text stays unchanged. Raw
recognition remains available for inspection, and matching manual corrections
take precedence.

The app includes the reviewed recording-worker source. New jobs receive an
immutable copy while retaining the existing local Python, models and speech-gate
setup. Existing jobs resume with their original runtime snapshots. No models are
downloaded by this update, and the global runtime configuration is not replaced.

The release retains 0.8.7's recording navigation, notes preservation, checkpoint
recovery and signed updater. Download and installation remain separate user
actions. Synthetic regression checks and a production build do not establish
live-call latency or transcription accuracy on future recordings.
