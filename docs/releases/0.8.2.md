# oats 0.8.2

Trelis dictation now sends confirmed phrases into the original focused text field while recording continues. Press **Ctrl+Alt+Shift+D** to start and again to finish the remaining speech. Starting from Settings produces a result to copy.

Phrase finalization requires about 600 ms of detected quiet, the next processing check and decoding. Continuous speech can wait until a pause or Stop. Focus/input interruption checks stop further insertion without changing words already delivered.

The faster-whisper experiment is retired after natural-speech recognition failed acceptance. Existing Trelis, meeting transcription, speaker configuration and notes remain separate from dictation's live-delivery path.

Validation covered the frontend export, optimized Windows package, synthetic worker/Settings/popup behavior and native streaming components. Installed read-only checks verified version, packaged resources, data preservation and model preparation. They did not exercise microphone capture, clipboard use or external text insertion. Physical Copilot behavior and destination-app compatibility require device-specific acceptance.

See [Dictation](../DICTATION.md) for the protocol, focus rules and limitations.
