# oats 0.8.3

The floating dictation indicator uses a 264 × 48 logical-pixel slim pill with a drag grip, status, microphone-level bars, Stop and Cancel. Copy recovery and errors expand into a panel. Deliberate moves are remembered across sessions, retained through phase changes and clamped to monitor space. The nonactivating popup preserves destination focus.

Pointer movement and scrolling do not interrupt live dictation while the original text box retains keyboard focus. Visual caret-location notifications are not treated as edits. Clicking elsewhere, keyboard edits/navigation, selection changes or switching fields still stop insertion and preserve the remaining result. Trelis phrase delivery and shortcuts are unchanged.

Saved meetings can be renamed by clicking their title. Enter or leaving the editor saves; Escape cancels. Invalid or failed saves retain the draft and existing title.

Updates notify before download, with separate **Download update** and **Install now** actions. Installation waits for saved notes and titles, refuses unresolved correction/reference/summary drafts and retained dictation text, and blocks active recording, speech processing and racing new work. Handoff preserves the chosen data location.

Signed Windows release automation is prepared for reviewed stable version tags. Activation requires repository configuration and a published signed release. Source pushes do not themselves update installed applications. Python/model provisioning for a new laptop remains separate.

Validation covered the production frontend, focused frontend and browser regressions, popup placement/input guards, Windows compilation, optimized NSIS packaging and signing helpers. Installed read-only inspection verified title cancellation, hidden popup layout, updater configuration and saved-data preservation. Installer bytes and authenticated version were verified against the build's public key.

These checks do not establish physical microphone, clipboard or target-app typing acceptance. Actual focus behavior, scaled multi-monitor placement and natural-speech latency require device-specific testing. The release feed and complete public update-installation path require separate qualification once a signed release is published.
