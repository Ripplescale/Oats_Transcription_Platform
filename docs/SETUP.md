# Set up oats

For a new PC, download **[Oats-Setup.exe](https://github.com/Ripplescale/Oats_Transcription_Platform/releases/download/setup-90c87eedfa370799c4dc/Oats-Setup.exe)**, open it, and click **Install oats**. Older copies call this **Download and install**. Setup downloads everything it needs; open oats from the Windows Start menu when it finishes.

**[Read the installation guide](COMPLETE_SETUP.md)** for the short steps, PC requirements, or transferring setup to a PC without internet.

Already have oats? Use **About → Check for updates** inside the app. You do not need the large setup again.

Only people building or changing the source code need the [developer guide](DEVELOPER_SETUP.md).
